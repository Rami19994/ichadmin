# iCHANCE Master Admin Key Generator & Gate Portal 👑

بوابة المالك المستقلة ولوحة توليد مفاتيح إدارة منصة **iCHANCE Casino & Sports**.

---

## 🌟 مميزات اللوحة المستقلة:
1. **توليد مفاتيح إدارة فورية معتمدة:** بنقرة واحدة تولد مفتاح إدارة جديد للوحة التحكم وتلغي المفاتيح القديمة.
2. **نسخ ودخول مباشر:** نسخ المفتاح بنقرة واحدة أو فتح لوحة الإدارة (`/admin`) مباشرة مع تسجيل الدخول التلقائي.
3. **مستقلة تماماً وقابلة للنشر على Vercel:** مشروع منفصل بالكامل يمكن ربطه بمستودع خاص ونشره على أي دومين (مثال: `https://ichadmin.vercel.app`).
4. **فحص حي لحالة خادم الألعاب:** مراقبة الاتصال وزمن الاستجابة (Ping) مع موقع `https://ichance.vercel.app`.
5. **إمكانية تدوير رمز البوابة السرية:** تغيير رمز الأمان عند الرغبة بسهولة وأمان.

---

## 🚀 طريقة النشر على Vercel:
1. ارفع المشروع إلى مستودع GitHub: `https://github.com/Rami19994/ichadmin.git`.
2. في حسابك على [Vercel](https://vercel.com)، اختر **Add New Project**.
3. اختر مستودع `ichadmin` واضغط **Deploy**.
4. سيتم النشر فوراً برابط مستقل جاهز للاستخدام!
